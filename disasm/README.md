# Disassemblies of the PC-1500 ROM dumps

Every dump in [`../dumps/`](../dumps) has an annotated disassembly here. Each one uses the
same file name with `.asm` and sits at the matching path:

```
dumps/a01/PC-1500-A01.BIN        ->  disasm/a01/PC-1500-A01.asm
dumps/a03/…, dumps/a04/…         ->  disasm/a03/…, disasm/a04/…
dumps/ce150/CE-150.BIN           ->  disasm/ce150/CE-150.asm
dumps/ce158/CE-158-{LOW,HIGH}.BIN ->  disasm/ce158/CE-158-{LOW,HIGH}.asm
```

All 6 sources reassemble **byte-identical** to their dumps (see
[Assembling](#assembling-back-into-bin)). Each file names its dump and that dump's MD5 in the
first lines.

- **Labels and comments.** Routines have names and header comments. The system ROM and the
  CE-158 carry the names of Jeff Birt's disassemblies
  ([PC-1500 ROM](https://github.com/Jeff-Birt/Sharp_PC-1500_ROM_Disassembly),
  [CE-158](https://github.com/Jeff-Birt/Sharp_CE-158)), corrected and checked against
  H.-G. Schlieker's "PC-1500 Intern" and the Technical Reference Manual. The CE-150 has no
  upstream source: it was annotated from Jeff Birt's symbol table, its keyword tables and the
  Technical Reference Manual.
- **Origin.** The files were generated by a separate annotation project. Lines such as
  "Generated by tools/romdis/… from ….ann — edit the .ann file", and references to
  `notes/…`, belong to that project; neither exists in this repository.
- **Dialect.** `sdas` (`sdaslh5801`) for the LH5801, the same as the dumper.

## What the ROMs contain

### System ROM (PC-1500 / PC-1500A)

| File | Seen at | Contents |
|---|---|---|
| `a01/PC-1500-A01`, `a03/PC-1500-A03`, `a04/PC-1500-A04` | C000H–FFFFH | The whole BASIC system. C000H: the main keyword table and the statement handlers, the screen editor and the key handlers. D000H: line and variable management, the expression evaluator, the BASIC stack. E000H: reset and power-on (RAM and module scan), interrupts, the keyboard, auto power off, the keyword-table search, PRINT / USING and the LCD output. EFB6H–F8FFH: BCD arithmetic and the functions. F900H: the tokenizer and the keyword dispatcher. FF00H: the vector table of the VEJ / VMJ calls. |

The three revisions have the same layout: no routine, vector or table moved.

### CE-150 (printer / plotter / cassette interface)

| File | Seen at | Contents |
|---|---|---|
| `ce150/CE-150` | A000H–BFFFH, PV = 0 | A000H: the plotter character strokes and the plotter driver (motors, pen, character drawing, LLIST, number formatting). B000H: keyword table 02 `MGP` (COLOR, CSIZE, GRAPH, LPRINT, LLIST, ROTATE, TEXT …). B800H: keyword table 01 `CMT` (CHAIN, CLOAD, CSAVE, MERGE, RMT), the tape routines and the system ROM's vector slots A4H–B8H. |

### CE-158 (RS-232C / Centronics interface)

| File | Seen at | Contents |
|---|---|---|
| `ce158/CE-158-LOW`, `ce158/CE-158-HIGH` | 8000H–9FFFH, PV = 1; PU selects the bank | 8000H: keyword table 08 `COM` (SETCOM, SETDEV, TERMINAL, DTE, TRANSMIT, ERN, ERL …). 8800H: keyword table 09 `LPRT` (CONSOLE, FEED, LPRINT, LLIST, TAB). Both banks hold the same tables and entry stubs; a keyword enters the low bank, which switches to the high bank through a stub in RAM (7A28H). The rest is the RS-232C and Centronics drivers, the terminal program and the serial CLOAD / CSAVE / MERGE. |

## What changed from A01 to A03 to A04

[`PC-1500-A0x-Revision-Differences.md`](PC-1500-A0x-Revision-Differences.md) goes through
every changed byte: what was wrong, what the fix does, and BASIC tests that show it. In short:

- **A01 → A03** (163 bytes, 30 places):
  - **BASIC:** string `<=` / `>=` decided by the wrong characters (`"AZ"<="BA"` is false on
    A01); `INPUT A` answered with `5)` gives `ERROR 0`. Smaller fixes in the GOTO/GOSUB line
    search, the DEF keys, RESERVE texts of exactly 26 characters and the out-of-memory check.
  - **Editor and display:** BUSY not shown during an ARUN start (wrong address), CL, ← and
    ↑/↓ display handling.
  - **Keyboard hook (79D4 = 55H):** broken on A01. A03 moves its vector to 785B/785C. The
    BASIC keyword manager [BASWORD](http://www.pc1500.com/basword.html) needs it and tests
    for it with `PEEK &E2B9` = 56 (A01: 213).
  - **Input buffer clear** now writes CR to 7C00 as well. On the PC-1500, 7C00 is a mirror of
    7800; on the PC-1500A it is separate RAM, which is why its machine-language area starts
    at 7C01.
- **A03 → A04** (151 bytes, 8 places), all in the BASIC interpreter:
  - **IF:** a negative condition counts as false on A01/A03 (`IF -1`, `IF NOT A`).
  - **FOR/NEXT:** the limit is tested before the step is added, so `FOR J=0 TO 10 STEP 3`
    runs a fifth time with J = 12.
  - **NOT/AND/OR:** a negative integer operand gives garbage (`NOT NOT 0` = −31233).
  - **USING, INPUT:** wrong error and a corrupted program pointer for a bad USING argument;
    the INPUT state is left set after ERROR 32.
- **Hardware:** no revision works around a hardware fault.

These results come from the code and from runs in the
[Calc-U-1600](https://github.com/tinue/Calc-U-1600) emulator with each ROM; they have not
been run on hardware.

## Assembling back into .BIN

Assembler and linker: **sdaslh5801**, **sdld** and **makebin** from the SDCC fork with the
LH5801 back end, https://github.com/pchambre/sdcc-pc1500. Build it as described in its
README. The tools end up in `sdcc/bin`.

Each source places itself at its address with `.org`. Link it, make a 64 KB image and cut out
the ROM:

```sh
sdaslh5801 -o PC-1500-A04.asm               # -> PC-1500-A04.rel
sdld -i PC-1500-A04.ihx PC-1500-A04.rel
makebin -s 65536 PC-1500-A04.ihx full.bin
tail -c 16384 full.bin > PC-1500-A04.BIN    # keep C000H-FFFFH
```

| Source | Cut out of `full.bin` |
|---|---|
| `PC-1500-A01`, `-A03`, `-A04` | `tail -c 16384` (C000H–FFFFH) |
| `CE-150` | `dd if=full.bin of=CE-150.BIN bs=1024 skip=40 count=8` (A000H–BFFFH) |
| `CE-158-LOW`, `CE-158-HIGH` | `dd if=full.bin of=CE-158-LOW.BIN bs=1024 skip=32 count=8` (8000H–9FFFH) |

### Check

Compare the result with the dump (`cmp PC-1500-A04.BIN ../dumps/a04/PC-1500-A04.BIN`), or its
MD5 with the one in the source header and in the top-level [README](../README.md#rom-images).
